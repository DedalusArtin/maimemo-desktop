【墨墨背单词桌面版】使用说明  v1.1.1
====================================

一、这是什么
  常驻屏幕右下角的墨墨风格学习悬浮窗 + 浏览器 Web 端,与墨墨背单词 App 双向联动:
  - 自动拉取你墨墨账号【今日要学习的单词】轮播巩固
  - 词义、例句来自墨墨账号数据,没有的自动用有道词典补全(带缓存,离线可用)
  - 单词 + 音标 + 词义 + 例句 + 发音(Edge 自然发音,断网自动切 Windows 内置)

二、安装 / 启动 / 关闭
  - 安装:双击「墨墨背单词-安装程序-v1.1.1.exe」→ 一路下一步(默认装到 D:\墨墨背单词)
  - 启动:双击桌面「墨墨背单词」快捷方式(或 D:\墨墨背单词\墨墨背单词.exe)
  - 关闭:点开悬浮窗 → 右上角 ✕
  - Web 端:双击桌面「墨墨背单词Web端」快捷方式(自动打开浏览器,端口 8790)
  - 开机自启(可选):把「墨墨背单词」快捷方式放进 Win+R → shell:startup
  - 卸载:设置 → 应用 → 墨墨背单词 → 卸载(或运行安装目录里的 unins000.exe)

三、操作方式(悬浮窗)
  紧凑模式:
  - 左键单击  :第一次=显示中文释义+例句,再点=下一个单词
  - 右键单击  :展开学习视图(词义列表/例句/认识/模糊/忘记/上一个/下一个)
  - 🔊 按钮   :不展开也能播放发音
  - ◀ 按钮    :回看上一个单词
  - ⏱ 自动/手动:右上角小标签点击切换(手动模式=完全自己翻词)
  展开模式:
  - ✓ 认识:已掌握,移出列表(记入 mastered.txt)
  - ~ 模糊:10 分钟后自动回来复习(本地间隔记忆,重启也有效)
  - ✗ 忘记:移到队尾,马上再看一遍
  - ◀ 上一个 / 下一个 → / ⏸ 暂停 / ▾ 收起
  - 添加单词:输入英文 →「查找」→ 预览词义/音标/例句 →「确认添加」(自动同步墨墨账号)
  - 📥 导入云词本:把墨墨App里云词本的单词批量导入
  - ⚙ 设置:token、轮播秒数、窗口角落、发音方式、自动轮播开关
  - 🔄 立即同步墨墨词表:改完 token 或网络恢复后,不用重启,一键重新拉取
  拖动:按住悬浮窗顶部区域拖到四个角,松手即吸附

四、和墨墨背单词 App 联动
  1. 手机 App:我的 → 更多设置 → 实验功能 → 开放 API,复制 token
  2. 悬浮窗 → 右键展开 → ⚙ 设置 → 粘贴 token → 保存 → 点「🔄 立即同步」
  3. 右上角标签变绿「墨墨已同步」即成功(Web 端右上角也能设置)
  注意(公测接口):需当天先在手机 App 打开过一次;App 里需开启"自动同步"

五、加单词的三种方式
  1. 悬浮窗展开 → 底部输入框 → 添加(自动同步墨墨)
  2. 编辑 D:\墨墨背单词\words.txt(每行: 单词 | 释义,# 开头为注释)
  3. 墨墨 App 里加的词,点「🔄 立即同步」后自动出现

六、常用文件(D:\墨墨背单词\)
  - config.json   设置 + 墨墨 token(隐私文件,请勿分享)
  - words.txt     本地词表        - mastered.txt  已掌握(删行可恢复)
  - review.json   模糊词复习状态  - cache.json   词典缓存
  - app.py + web/ 源码           - web版/       Web 端(server.py 本地服务器)
  - installer/    安装包脚本(重新打包用)

七、常见问题
  - 悬浮窗不显示词:token 没填/当日没开过 App;或 words.txt 没词
  - 同步失败:把鼠标悬停在左上角状态标签,会显示具体原因:
    · token 无效/过期 → 去 App 实验功能重新复制
    · 连不上服务器 → 检查网络/代理,恢复后点「🔄 立即同步」
    · 接口限流 → 稍等几分钟再试
  - 想改界面:改 web/index.html 后用 installer 里的命令重新打包
  - 分享/传播安装包安全:安装包不含你的 token 和学习记录
