【墨墨背单词桌面版】使用说明
====================================

一、这是什么
  一个常驻屏幕右下角的墨墨风格学习悬浮窗:
  - 自动轮播单词:先显示单词 → 再显示音标/释义 → 换下一个
  - 点击悬浮窗展开成完整学习卡片:词义列表 + 例句(单词高亮)+ 发音
  - 与墨墨背单词 App 双向联动(需配置 token,见第三节)
  - 不联动也能用:本地 words.txt 词表 + 有道词典自动补全音标/词义/例句

二、怎么启动 / 关闭 / 移动
  - 启动:双击「墨墨背单词.exe」(绿色便携版,放哪都能跑)
  - 关闭:点开悬浮窗 → 右上角 ✕
  - 移动:拖动悬浮窗顶部区域到四个角之一(松手即吸附),
          或在设置里选"窗口角落"
  - 开机自启(可选):把「墨墨背单词.exe」的快捷方式放进
    Win+R → shell:startup

三、和墨墨背单词 App 联动(关键!)
  1. 手机墨墨背单词 App:我的 → 更多设置 → 实验功能 → 开放 API,
     获取你的 token(也可以 https://open.maimemo.com/#/ 获取)
  2. 电脑上点开悬浮窗 → ⚙ 设置 → 粘贴 token → 保存
  3. 重启悬浮窗,右上角标签变绿「墨墨已同步」即成功
  效果:
  - 自动拉取你墨墨账号【今日要学习的单词】到悬浮窗轮播
  - 词义、例句来自你账号的数据(没创建过的自动用有道补全)
  - 在悬浮窗"添加单词"→ 会同步添加到你的墨墨账号(双向联动)
  注意(公测接口限制):
  - 需要当天先在手机 App 里打开过一次(初始化今日词表)
  - 需要在 App 里开启"自动同步"(实验功能页)
  - 接口限频:60秒40次,5小时2000次 —— 程序已做缓存,正常使用不会超

四、加单词的三种方式
  1. 悬浮窗展开 → 底部输入框 → 添加(有 token 时自动同步墨墨)
  2. 编辑本文件夹的 words.txt(每行: 单词 | 释义,# 开头为注释)
  3. 墨墨 App 里加的词,电脑端重启后自动出现(若开了自动同步)

五、常用文件
  - words.txt      本地词表(每行"单词 | 释义")
  - mastered.txt   已掌握单词(自动记录,删行可恢复)
  - config.json    设置:token、轮播秒数、角落、发音方式
  - cache.json     词典缓存(联网查过的音标/词义/例句,离线也能用)
  - app.py + web/  源码(想改界面/功能可以自己改,或用它重新打包)

六、发音说明
  - 默认 Edge 自然发音(需联网);断网时自动切换 Windows 内置发音
  - 设置里可手动切换两种发音方式

七、常见问题
  - 悬浮窗不显示词:确认 token 填了且 App 当日开过;或检查 words.txt 有词
  - 墨墨同步失败:网络问题或 token 过期,去 App 实验功能重新获取
  - 想恢复已掌握的词:打开 mastered.txt 删掉对应行,重启
